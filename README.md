# 愛知県 平面直角座標変換

ブラウザーで動作する、平面直角座標系の X・Y・Z から JGD2011 の緯度・経度（10進数）と高さ情報を表示する小さなWebアプリです。

## 起動

`index.html` をブラウザーで開くか、リポジトリを GitHub Pages などの静的ホスティングに配置してください。外部ライブラリやビルド工程は不要です。HTTPS経由での利用を推奨します。

## 入力・出力

- 初期座標系は平面直角座標系 第VII系（愛知県）。必要に応じて第VI系・第VIII系も選べます。
- X＝北方向、Y＝東方向（いずれもm）。
- Z＝JGD2011楕円体高（m）として解釈します。
- 緯度・経度はGRS80を用いた逆投影で計算します。
- ジオイド高は国土地理院測量計算サイトのAPIを、地理院標高は国土地理院DEM APIをブラウザーから呼び出します。
- 計算標高は `Z − ジオイド高` で算出します。DEM標高は別途表示し、入力Zからの計算標高と混同しないようにしています。

## 座標系・高さの注意

入力データのX/Yの軸順、単位、系番号、測地系を必ず確認してください。平面直角座標系の系番号が違うと結果が大きくずれます。第VII系は愛知県内の多くの地域で使われますが、県全域でデータの座標系を自動判別するものではありません。Zが標高（正標高）や別の基準面の高さなら、このアプリの標高計算にはそのまま使えません。JGD2011楕円体高を入力してください。

外部APIへの接続が制限されている環境、API仕様の変更、または対象外の場所ではジオイド高・DEM標高が表示できない場合があります。測量成果に用いる前に国土地理院の公式サイトで照合してください。
